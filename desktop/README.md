# EhViewer Desktop

这是一个基于Java Swing的桌面图像查看器，支持浏览文件夹和ZIP/CBZ压缩包中的图像。

## 功能特性

- 支持打开文件夹和ZIP/CBZ压缩包
- 支持常见图像格式：JPG, JPEG, PNG, GIF
- 图像缩放功能（放大、缩小、适合窗口、实际大小）
- 键盘快捷键支持
- 自然排序（数字按数值排序）

## 键盘快捷键

- `←` / `→` - 上一张/下一张图片
- `+` / `=` - 放大
- `-` - 缩小
- `F` - 适合窗口
- `1` - 实际大小
- `Esc` - 退出程序

## 构建和运行

### 构建
```bash
./gradlew desktop:build
```

### 运行
```bash
./gradlew desktop:run
```

## 使用方法

1. 启动应用程序
2. 使用菜单 "File" -> "Open Folder..." 打开包含图像的文件夹
3. 或使用 "File" -> "Open Zip..." 打开ZIP/CBZ压缩包
4. 使用底部按钮或键盘快捷键浏览和缩放图像

## 技术细节

- Java 11+
- Swing GUI框架
- 支持递归扫描文件夹中的图像
- 高质量图像缩放算法
