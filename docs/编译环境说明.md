# 编译环境说明

本文档说明本工程 HarmonyOS 构建所需的编译环境与工具路径。

## DevEco Studio

- **用途**：HarmonyOS / OpenHarmony 应用开发 IDE，提供 ohpm、hvigor、SDK 等构建与调试能力。
- **本机安装路径**：
  ```
  /Volumes/Brave 2T/Applications/DevEco-Studio.app
  ```
- **官网**：<https://developer.harmonyos.com/cn/develop/deveco-studio>

使用本工程进行构建或调试时，请用上述路径下的 DevEco Studio 打开项目根目录；ohpm、hdc 等命令行工具需使用 DevEco Studio 自带的终端或已配置的 PATH，以便正确找到对应版本。

## 打包 HAP 安装包

1. **首次构建前**：用 DevEco Studio 打开本工程根目录，若提示「项目结构/配置需要升级」，按提示完成迁移（Migration）。
2. **在 IDE 内打包**：菜单 **Build → Build Hap(s)/APP(s) → Build Hap(s)**，即可生成 HAP。
3. **命令行打包（可选）**：迁移完成后，在终端执行：
   ```bash
   # 可选：指定 DevEco 路径（默认已为本机路径）
   export DEVECO_STUDIO_APP="/Volumes/Brave 2T/Applications/DevEco-Studio.app"
   npm run build
   ```
   HAP 输出路径：`entry/build/default/outputs/default/entry-default-unsigned.hap`（未签名，可用于调试安装）。
