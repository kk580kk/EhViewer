# 00 - 总览与排期

## 项目目标

- 将 EhViewer Android 端业务用 ArkTS 在 HarmonyOS 上实现功能对等
- 覆盖网络请求、HTML/API 解析、下载、图库浏览、设置、全部主要 UI 与交互
- 不包含 Android 专属能力（如 GMS、Fabric）、与 E-Hentai 无关的第三方 SDK

## 模块与规模概览

| 模块 | Java 文件数（约） | 说明 |
|------|-------------------|------|
| client（含 data/parser/exception） | 50+ | 请求、数据模型、解析、异常 |
| download | 2 | 下载管理与服务 |
| gallery | 5 | 图库提供者、压缩包等 |
| spider | 3 | 爬虫核心 |
| preference / Settings / EhDB | 20+ | 设置与持久化 |
| ui（含 scene） | 50+ | 页面、场景、对话框 |
| widget（ehviewer 内） | 20+ | 列表项、搜索栏等业务组件 |
| hippo 公共（util, network, app, widget 等） | 120+ | 工具、网络、UI 基类等 |

合计约 **272** 个 Java 文件（不含测试与 daogenerator）。

## 阶段划分与依赖关系

```
Phase0: 基础层与依赖映射
    ↓
Phase1: 数据模型与客户端核心（EhEngine、解析、请求）
    ↓
Phase2: 下载与图库模块
    ↓
Phase3: 设置与偏好
    ↓
Phase4: UI 与页面（依赖 Phase1~3）
```
