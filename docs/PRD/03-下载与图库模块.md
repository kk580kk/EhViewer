# 03 - 下载与图库模块

实现画廊下载管理、下载任务调度、以及本地/压缩包图库的浏览能力。依赖 02 的 EhEngine/EhClient 与 01 的存储、流、文件路径。

## 下载管理

- [x] 实现 `DownloadManager`：维护下载队列（待下载/下载中/已完成/失败）
- [x] 实现下载任务添加、取消、重试、删除功能
- [x] 将下载任务与 `GalleryInfo` 绑定，持久化任务列表（使用 01 的 DB 或 Preferences）
- [x] 实现应用重启后恢复下载状态的逻辑
- [x] 实现下载进度与状态回调，供 UI 显示进度条与状态文本
- [x] 实现并发数控制（限制同时下载数量）
- [x] 实现重试策略（失败重试、509 等错误处理），与 Android 行为一致
- [x] 实现 `DownloadService` 或等价后台执行能力（Harmony 后台任务/长时任务）
- [x] 确保应用退到后台时下载可继续（在系统允许范围内）
- [x] 下载文件落盘路径符合 01 的文件规范，支持选择目录
- [x] 支持迁移已下载目录

## 爬虫（Spider）

- [x] 实现 `SpiderInfo`：描述单次爬取任务（画廊、范围、保存路径等）
- [x] 实现 `SpiderQueen` / `SpiderDen`：根据 SpiderInfo 调用 EhEngine 获取图页 URL
- [x] 实现按顺序下载图片并写入本地，更新进度
- [x] 支持爬虫任务的暂停/恢复/取消
- [x] 实现爬虫与 DownloadManager 协同调度

## 图库提供者（GalleryProvider）

- [ ] 定义 `GalleryProvider2` 接口：统一「图库 → 图片列表」访问能力
- [ ] 实现 `EhGalleryProvider`：在线画廊，通过 EhEngine 获取图页并加载图片 URL
- [ ] 为 `EhGalleryProvider` 添加缓存策略
- [ ] 实现 `DirGalleryProvider`：本地目录图库，扫描目录下图片文件
- [ ] 为 `DirGalleryProvider` 添加排序与分页支持（若需）
- [ ] 实现 `ArchiveGalleryProvider`：从压缩包（zip/7z）内读取图片列表
- [ ] 实现压缩包内图片流式解压读取
- [ ] 实现 `Pipe` 或等价流式读取接口，供压缩包内图片逐张读取
- [ ] 实现或集成 7z 解压能力（`A7ZipArchive`）；若无现成 ArkTS 库，先支持 zip，7z 列为后续

## 与 UI 的衔接

- [ ] 提供「当前图库来源」与「当前页索引」的只读状态，供阅读页与导航栏使用
- [ ] 下载列表/图库列表的数据源可被 05 的列表页绑定，支持刷新与点击进入详情/阅读

## 验收标准

- [ ] 用户可对指定画廊发起下载，任务进入队列并持久化，进度与状态正确展示
- [ ] 下载可在后台进行（在 Harmony 后台策略允许下），支持暂停/恢复/取消
- [ ] 已下载画廊可作为本地图库打开，目录与压缩包内图片可逐张浏览
- [ ] 在线画廊、本地目录、zip（及可选 7z）三种来源的阅读体验与 Android 端对等
