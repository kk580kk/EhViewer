# 04 - 设置与偏好

实现应用配置的读写、持久化与 UI 展示。依赖 01 的 Preferences/键值存储与数据库；与 02 的 EhConfig 联动，与 05 的设置页 UI 配合。

## Settings 核心

- [x] 实现 ArkTS 版 `Settings` 单例或模块：初始化时从 01 的持久化层读取
- [x] 提供 get/put 接口（boolean, int, long, string, string set 等）
- [x] 实现所有 Android Settings 中的 key 与默认值（图片分辨率、排除语言、默认分类、代理、主题、下载路径、安全锁等）
- [x] 编写 Settings key 与默认值对照配置表
- [x] Settings 变更时同步更新 EhConfig（图片尺寸、排除语言、排除标签命名空间、默认分类等）
- [x] Settings 变更时触发 UI 或客户端刷新（若需）
- [x] 实现按地区默认开启内置 Hosts 等「首次默认值」逻辑（与 Android fixDefaultValue 一致）

## EhDB 与数据持久化

- [x] 实现 `EhDB`：基于 01 的 RelationalStore/DAO，定义全部表结构
- [x] 实现历史记录表：按时间排序、分页查询
- [x] 实现历史记录删除单条功能
- [x] 实现历史记录清空功能
- [x] 实现收藏表：支持分类与标签
- [x] 实现收藏与站点收藏夹同步策略（本地记录 + 可选远程同步）
- [x] 实现下载记录表：与 DownloadManager 对应，记录已下载画廊与路径
- [x] 实现下载记录恢复与清理
- [x] 实现标签/命名空间存储表：存储用户使用的标签与排除项
- [x] 实现搜索记录存储：供列表过滤与搜索使用

## 设置项 UI 与行为

- [x] 实现「代理」设置：UI 可配置代理类型与地址，保存到 Settings，在 HTTP 客户端中生效
- [x] 实现「排除语言」设置：多选 UI，写入 Settings 与 EhConfig
- [x] 实现「排除标签命名空间」设置：多选 UI，写入 Settings 与 EhConfig
- [x] 实现「默认分类」设置：列表 UI，写入 Settings 与 EhConfig
- [x] 实现「下载路径」选择：调用系统目录选择或 Harmony 文件选择能力，路径持久化
- [x] 实现「清除下载路径缓存」任务型偏好：触发 DownloadManager 的对应操作并给出结果提示
- [x] 实现「恢复下载」任务型偏好：触发 EhDB 的对应操作并给出结果提示
- [x] 实现「登录状态」展示：显示当前登录状态
- [x] 实现「登出」功能：清除 Cookie，跳转登录页
- [x] 实现「身份 Cookie」展示与操作
- [x] 实现「导出数据」功能：导出历史/设置等
- [x] 实现「清理冗余」功能：清理缓存与冗余文件
- [x] 实现「版本信息」展示与「关于」入口（版本号、许可等）

## 安全与隐私

- [x] 实现安全锁设置项（密码/图案）：开启后进入应用或敏感页需验证
- [x] 实现安全锁验证逻辑，与 Android SetSecurityActivity/LockPattern 对等
- [x] 敏感配置（如 Cookie、密码）存储时使用 Harmony 安全存储或加密（若平台提供）

## 验收标准

- [x] 所有 Android 端存在的设置项在 Harmony 端可配置并持久化，重启后生效
- [x] EhDB 各表可正确读写，历史/收藏/下载记录在 UI 中展示与操作一致
- [x] 代理、排除语言、下载路径等变更后，客户端与下载模块能立即使用新配置
- [x] 登录状态、安全锁、导出与清理功能与 Android 端行为对等
