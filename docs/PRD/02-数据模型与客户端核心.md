# 02 - 数据模型与客户端核心

实现 E-Hentai 站点相关的数据模型、请求构建、响应解析与统一入口（EhEngine）。依赖 01 基础层（HTTP、HTML 解析、Cookie、存储）。

## 数据模型（与 entry 现有 model 对齐）

- [x] 补全并统一 `GalleryInfo`（entry 已有）：gid, token, title, titleJpn, thumb, category, uploader, posted, rating, pages, tags, simpleLanguage 等字段与语言常量
- [x] 实现 `GalleryDetail`（entry 已有）：画廊详情页全部字段与预览信息
- [x] 实现 `GalleryTagGroup`：标签组结构，与 Android 一致
- [x] 实现 `GalleryComment` 与 `GalleryCommentList`：评论数据结构
- [x] 实现 `GalleryPreview`、`PreviewSet`、`NormalPreviewSet`、`LargePreviewSet`：缩略图与预览集
- [x] 实现 `GalleryApiInfo`：API 返回数据结构
- [x] 实现 `ListUrlBuilder`：列表 URL 构建，支持搜索/分类/标签等参数
- [x] 实现 `FavListUrlBuilder`：收藏夹列表 URL 构建

## 异常体系

- [x] 实现 `EhException` 基类异常
- [x] 实现 `ParseException` 解析异常
- [x] 实现 `CancelledException` 取消异常
- [x] 实现 `NoHAtHClientException` 无 H@H 客户端异常
- [x] 实现 `Image509Exception` 图片 509 限制异常
- [x] 实现 `OffensiveException` 敏感内容异常

## 请求与配置

- [x] 实现 `EhConfig`（entry 已有占位）：站点域名、Cookie、User-Agent、图片大小等配置项
- [x] 实现 `EhUrl`（entry 已有占位）：各类页面/API 的 URL 生成（列表、详情、图页、登录等）
- [x] 实现 `EhUtils`（entry 已有占位）：签名、请求头、Cookie 处理等工具方法
- [x] 实现 `EhRequest` / `EhRequestBuilder`：基于 01 HTTP 客户端构建 GET/POST，支持 Header、Body、Cookie 注入
- [x] 实现 `EhCookieStore`：与 01 的 Cookie 层对接，支持按域名读写
- [x] 实现 `EhFilter`：过滤条件存储与查询
- [x] 实现 `EhTagDatabase`：标签库存储与查询接口
- [x] 实现 `EhCacheKeyFactory`：图片/资源缓存 Key 生成规则
- [x] 实现 `EhDns`：自定义 DNS 解析（若需）
- [x] 实现 `EhUrlOpener`：外链与系统浏览器跳转（若需）
