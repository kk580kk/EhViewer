# 01 - 基础层与依赖映射

基础层提供：工具类、网络封装、Cookie/存储、数据库抽象、以及 Android 第三方库在 Harmony 上的替代方案。客户端与 UI 均依赖本层。

## 第三方库与 Harmony 替代

| Android 依赖 | 用途 | Harmony/ArkTS 替代方案 |
|--------------|------|------------------------|
| OkHttp 3.12 | HTTP 请求 | @ohos.net.http 或 axios 等 HTTP 能力 |
| jsoup 1.12 | HTML 解析 | 自研或移植轻量 HTML 解析 / 正则+DOM 等价 |
| TagSoup | 不规范 HTML | 同上或简化解析规则 |
| greenDAO 2.2 | ORM / 本地 DB | 关系型数据库 RelationalStore + 手写或轻量封装 |
| seven332/* | 图片加载、图库 UI | Harmony 图片组件 + 自定义缓存与解码 |

## 工具类迁移

- [x] 实现 ArkTS 版 `ReadableTime`（时间友好显示），与 Android 行为一致
- [x] 实现 ArkTS 版 `NaturalComparator` / `PathNaturalComparator`，用于文件名/路径自然排序
- [x] 实现 ArkTS 版 `ExceptionUtils`（异常链、消息提取），供全局错误处理使用
- [x] 实现 ArkTS 版 `HashCodeUtils`，用于对象哈希与集合键
- [x] 实现 ArkTS 版 `IoThreadPoolExecutor` 或等价后台任务调度（Worker/TaskPool），供解析与 IO 使用
- [x] 实现 ArkTS 版 `LogCat` / 日志工具，支持级别与 TAG，可对接系统日志
- [x] 实现 ArkTS 版 `MutableBoolean` 及常用可变容器（若 ArkTS 无等价）
- [x] 实现 ArkTS 版 `TextUrl`（文本与 URL 解析/高亮）或合并到 UI 层链接处理
- [x] 实现 ArkTS 版 `JsoupUtils` 或封装 HTML 解析工具，供 Parser 使用
- [x] 将 `AppHelper`、`PackageUtils`、`PermissionRequester` 中与包名/权限相关逻辑用 Harmony API 重写

## 网络与 Cookie

- [x] 基于 @ohos.net.http（或选定 HTTP 库）封装统一 HTTP 客户端，支持 GET/POST、Header、Body、超时
- [x] 实现 `UrlBuilder` 等价能力（查询参数拼接、编码）
- [x] 实现 `StatusCodeException` 及 HTTP 错误码处理规范
- [x] 实现 Cookie 存储与携带：持久化（如 Preferences 或 DB）、请求时自动附加（对应 CookieRepository/CookieSet/CookieDatabase）

## HTML 解析
