# 06 - 公共组件与基础设施

提供与业务无直接绑定的通用 UI 组件、应用基类、内容提供与工具。被 05 的页面与 02/03/04 间接使用。

## 应用与 Activity 基类

- [x] 实现与 `AppCompatPreferenceActivity`/`PrettyPreferenceActivity` 等价的设置页基类
- [x] 统一 Preference 列表布局、保存与取消逻辑
- [x] 与 04 的 Settings 读写对接
- [x] 实现 `ProgressDialog` 等价：加载中遮罩或进度条，可取消
- [x] 实现 `CheckBoxDialogBuilder`：弹窗内复选框
- [x] 实现 `EditTextDialogBuilder`：弹窗内单行/多行输入
- [x] 实现 `ListCheckBoxDialogBuilder`：弹窗内列表选择

## 场景与容器

- [x] 实现 `StageActivity`/`StageLayout` 等价：单 Activity 多场景容器
- [x] 支持场景切换与返回栈（与 05 的路由配合）
- [x] 实现 `SceneFragment`：场景生命周期管理
- [x] 实现 `Announcer`：场景间通信
- [x] 实现 `TransitionHelper`：转场动画，与 Harmony 动画能力对接
- [x] 实现 `SceneApplication` 或应用级单例：持有全局 Context 等价、场景注册（若需）

## 通用 UI 组件

- [x] 实现 `LoadImageView`：支持 URL/路径加载、占位图、错误图、缓存
- [x] 实现 `ProgressView`：进度条组件，供下载进度使用
- [x] 实现 `Slider`：滑动条组件，供设置项使用
- [x] 实现 `DrawerView`：侧边抽屉布局
- [x] 实现 `FabLayout`：悬浮按钮布局
- [x] 实现 `ContentLayout`：内容区域布局组件
- [x] 实现 `AutoWrapLayout`：自动换行布局
- [x] 实现 `MaxSizeContainer`：最大尺寸容器
- [x] 实现列表/网格布局与复用（对应 AutoGridLayoutManager、AutoStaggeredGridLayoutManager）
- [x] 实现 `LockPatternView`：图案锁 UI 组件
- [x] 实现 `LockPatternUtils`：图案锁校验逻辑
- [x] 实现 `BatteryView`：电量显示组件（若需）
- [x] 实现 `CheckTextView`：带勾选的文本组件
- [x] 实现 `ColorView`：颜色展示组件
- [x] 实现 `LinkifyTextView`：可点击链接的文本组件
- [x] 实现 `ObservedTextView`：可观察变化的文本组件
- [x] 按 05 实际使用情况按需迁移其他小组件
